# Worked example — how to read this folder

A complete research note built by applying the pack, not a
template filled with demo numbers. (The repo's `examples/`
folder still holds the DEMO-data format example; this folder
is the real-subject proof that the agents and runbooks work
together end to end.)

## Contents

- [bottlers-nepal-terai-bnt-research-note.md](bottlers-nepal-terai-bnt-research-note.md)
  — the full note: run contract, frozen input ledger (Ledger
  Controller), recomputed financials, forensic flags, market
  context, Nepal frictions, Bull/Bear debate with each argument
  answered, three risk scenarios with triggers (Risk Stance
  Analyst), a Risk Veto verdict, an accuracy audit, open
  questions, and sources. Runbook: `runbooks/structured-debate.md`.

## What this example proves — and what it does not

**Proves:** the ledger freeze (§1 of the note), the parallel
analyst reports, the structured debate with a genuine
disagreement and a surviving losing argument, the three
triggered risk scenarios, and the publication gate all work on
real, sourced inputs with every figure cited or labelled
UNKNOWN.

**Does not prove, and does not claim:** a valuation (no DCF,
no target, no valuation conclusion), a current price (the run
is frozen as of 2026-10-16; the current BNT price is UNKNOWN
here), a news/sentiment read (no dated count was sourced),
or any buy/sell/hold recommendation. Research only.

## Honesty rules for reusing this example

1. Keep the as-of date (2026-10-16) attached to every figure
   taken from the note. October 2026 closes are not current
   prices.
2. Keep the "unaudited" label on every FY 2082/83 quarterly
   figure. The audited FY 2081/82 year is the anchor.
3. Keep the limits with the verdict: this note published
   **with limits**, not unconditionally — thin price legs,
   the ~Rs 81M bridge gap, and the UNKNOWN fate of the
   Rs 763M tax provision travel with it.
4. Do not count this folder as a runbook. Runbooks live in
   `runbooks/` and are counted by the roster check; this is
   documentation. The pack remains **18 agents + 1 guide file
   (`agents/WHEN-TO-USE.md`) and 10 runbooks**.
