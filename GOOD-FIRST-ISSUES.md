# Good First Issues

Small, well-scoped tasks a new contributor can pick up. This is a list, not
a promise: no maintainer response time is promised, and no GitHub issue has
been created for these items. Open an issue first and ask to be assigned
before starting, so two people do not do the same task.

## 1. Retrofit Inputs/Outputs (and Success metrics) onto one original agent

The 10 original agents below do not yet have the two template sections that
new agents carry (see `README.md` → Contributing): **Inputs/Outputs**
(the handoff contract — what the agent takes in and what it hands on) and
**Success metrics** (how "done" is judged). Retrofit exactly one agent per
contribution, following the format of a newer agent such as
`agents/data-scout.md`.

## House rules

Research only, not investment advice; never a buy/sell recommendation.
No credentials, no private data, no paywalled scraping.
